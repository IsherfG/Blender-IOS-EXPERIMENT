# 3D Modeling Thingy

3D Modeling Thingy is an independent app based on Blender, adapted for iPhone
and iPad. It keeps the desktop interface, adds touch controls, and works with
ordinary `.blend` files. It is not affiliated with or endorsed by the Blender
Foundation.

## Get started

- [Install the app](https://shlok-bhakta.github.io/3d-modeling-thingy-ios/install/).
- [Learn the touch controls](https://shlok-bhakta.github.io/3d-modeling-thingy-ios/controls/touch/).
- [Check the limitations](https://shlok-bhakta.github.io/3d-modeling-thingy-ios/limitations/), including add-ons and rendering.

The [user guide](https://shlok-bhakta.github.io/3d-modeling-thingy-ios/) covers
files, windows, keyboards, and Apple Pencil. For modeling tools and other
features inherited from Blender, see the [Blender Manual](https://docs.blender.org/manual/en/5.2/).

## Development

This repository contains the modified source and iOS build scripts. Start with
the [iOS handoff](docs/ios/HANDOFF.md) for build instructions and the
[architecture notes](docs/ios/ARCHITECTURE.md) for the port's design.
The [docs-site README](docs-site/README.md) explains how to build the user guide.

Blender's [upstream project](https://www.blender.org) and
[developer documentation](https://developer.blender.org/docs/) cover the original
software. Report problems with this app in
[this repository](https://github.com/Shlok-Bhakta/3d-modeling-thingy-ios/issues).
